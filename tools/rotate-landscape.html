Rotate the landscape printings

26 of 158 printings are landscape — every one a Structure — and Palify serves them already landscape. The deck's card cells are portrait, so in-world they arrive squashed rather than turned. Nothing in Resonite can fix that: TextureScale/TextureOffset reach the shader as _Tex_ST and are applied as uv * scale + offset, which can scale and translate each axis but cannot swap them. The rotation has to be in the pixels.

This runs the same rotation the deck bake ships. web/imgfix.js's toImageData(src, 90), verbatim — centre, rotate, swap width and height. The direction has been got wrong twice in this project, both times silently, so it is copied rather than re-derived.

Check the pairs below before you commit anything. Every card should read upright on the right. If they all read upside down, the constant is wrong — and that is exactly the bug that shipped twice.
